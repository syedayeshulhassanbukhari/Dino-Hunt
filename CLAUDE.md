# Orientation for Claude Code

## What this project is

Building **Primal Rift: Outpost Siege** (dinosaur co-op wave shooter) by reskinning the
**Dino Valley** Roblox place (placeId `88638180383535`), which today runs a finished Area 51
alien wave shooter. See [README.md](README.md) for the three-names table — the directory,
the repo, the product and the place all have different names.

## How to reach the game

Roblox Studio MCP bridge. Get the instance id first:

- `list_roblox_studios` → returns the Dino Valley instance id
- Every other Studio call needs that `studio_id`
- `datamodel_type` is `Edit` unless play-testing

**Read before writing.** The place contains a large working codebase that real players use.
Nothing in it was written for Primal Rift.

## Conventions the existing code already holds to

These are load-bearing. Preserve them unless a decision in
[docs/03-open-decisions.md](docs/03-open-decisions.md) says otherwise.

- **Numbers are derived, not hand-tuned.** Every enemy stat descends from one difficulty
  weight `lp`: `baseHP = 15 x lp`, `damage = 4.5 x sqrt(lp)`, `gearDamage = 20 x sqrt(lp)`,
  `gemReward = 10 x sqrt(lp)`, `coinReward = 5 x sqrt(lp)`. Speed comes from the role.
- **The wave-1 enemy dies to exactly one starter-weapon shot.**
- **Every enemy is slower than the player's 17.6** — anything can be outrun.
- **Nothing one-shots a base-HP player.**
- Concurrency is `min(perPlayer x livePlayers, MAX_ACTIVE_ZOMBIES=60)`, one server-wide cap.
- The server owns damage, ammo, currency, drops and saves. The client never reports a hit.
- Comments in this codebase explain *why* a number is what it is, with dates and who asked.
  Match that. A bare number with no derivation is out of place here.

## Traps

- `ReplicatedStorage.Shared.*` is a **dead SWAT-game framework** from an unrelated project
  (Net, Validate, RateLimiter, Progression, RankConfig, MissionConfig, GearConfig). Largely
  unread by the live game. Do not assume it is the service layer — see open decision D-04.
- Enemy templates are duplicated across `Workspace`, `ReplicatedStorage`, `ReplicatedFirst`
  and `ServerStorage`, plus a dated backup. The spawner uses `ServerStorage.ZombieTemplates`.
- `WaveTable` is generated by `tools/gen_wavetable.js` from `docs/AREA51_WAVE_TABLE.md`,
  neither of which is in this repo. See open decision D-02.
- Several `ZZZ_*`, `_DEBUG_*` and `_QA_*` diagnostic scripts are live in the place. Some are
  useful for testing waves; do not delete them casually.

## Source of truth

The **place is the source of truth for game code**. `Roblox-Zombie-Arena` is not synced into
it (decided 2026-09-06) and Rojo is not in use — all iteration happens over the MCP bridge.
This repo holds documentation and design data. See open decision D-06 on the version-control
gap that follows from this.
